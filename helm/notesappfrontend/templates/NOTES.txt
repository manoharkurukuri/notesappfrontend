The chart creates notesappfrontend-config with API_URL from configMap.apiUrl.
Replace the dummy configMap.apiUrl in values.yaml with your real public API URL.
Configuration changes roll out new pods automatically.
Readiness checks /api/runtime-config; startup and liveness checks use /.
No custom ServiceAccount is created; service account token mounting is disabled.

Route resources are controlled by ingress.enabled or httpRoute.enabled.
Check the matching controller or Gateway before enabling one.

For local access:
  kubectl --namespace {{ .Release.Namespace }} port-forward service/{{ include "notesappfrontend.fullname" . }} 3000:{{ .Values.service.port }}
